# ShipList

Una aplicación sencilla para organizar tareas, con una interfaz adaptable a celulares y guardado automático en el navegador.

## Funciones

- Agregar y eliminar tareas.
- Marcar tareas como completadas.
- Filtrar por todas, pendientes o hechas.
- Limpiar las tareas completadas.
- Consultar el progreso de la lista.
- Guardar las tareas localmente con `localStorage`.

## Uso

Abre `index.html` en un navegador moderno. No requiere instalación ni dependencias.

Las tareas se guardan en el navegador utilizado y no se sincronizan entre dispositivos. Si borras los datos del sitio, también se borran las tareas. El guardado al abrir archivos locales puede variar según el navegador.

## Tecnologías

- HTML
- CSS
- JavaScript

## Estructura

```text
index.html   Contenido y estructura de la página
styles.css   Diseño y estilos adaptables
app.js       Tareas, filtros y almacenamiento local
```
